# Security Policy

## Supported versions

Only the latest published Pi Mentis version is supported. The current release supports
`@earendil-works/pi-coding-agent` 0.83.0 exactly.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability
reporting for `guchengod/pi-mentis`. Include affected versions, reproduction steps, impact, and any
suggested mitigation. Avoid including real credentials or private memory data.
